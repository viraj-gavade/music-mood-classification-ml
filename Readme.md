# Music Mood Classification (MathWonder Event)

This repository contains a deep learning project for music mood classification, developed as a college project for the **MathWonder** event.

## Project Overview
- **Purpose:** Predict the mood of a music track using audio features and deep learning.
- **Technologies:** PyTorch, Streamlit, FastAPI (for future extension), NumPy, scikit-learn, and more.
- **Models:** Custom CNN and MLP hybrid model for feature extraction and classification.
- **Frontend:** Streamlit app for easy demo and interaction.

## Features
- Audio file upload and mood prediction
- Real-time inference and visualization
- Hybrid model combining CNN (for spectrograms) and MLP (for mathematical features)
- Designed for educational and demonstration purposes

## Usage
1. Install requirements:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the Streamlit app:
   ```bash
   streamlit run app_v2.py
   ```
3. Upload an audio file and view the predicted mood.
